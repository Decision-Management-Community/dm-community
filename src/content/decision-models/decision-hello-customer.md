A small, self-contained example decision model: it decides how to greet a customer using inputs
like gender, marital status, age, and the current time of day. It was listed in the old site's
Miscellaneous decision-models category as a simple illustrative model (as opposed to the larger
banking/insurance/healthcare examples elsewhere in this collection).

**The link is broken.** `decisionmodels.wordpress.com` now serves a WordPress.com "Private Site"
wall for every page on the domain, including this one — the content itself is no longer publicly
reachable, even though the domain still resolves with an HTTP 200. Kept here as a record in case a
working copy turns up — see [CONTRIBUTING.md](https://github.com/Decision-Management-Community/dm-community/blob/main/CONTRIBUTING.md)
if you can find one via the Wayback Machine or elsewhere.
