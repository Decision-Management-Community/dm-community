---
title: Oracle Adds DMN Preview to Process Cloud Service
vendor: Oracle
date: 2018-05-01
url: "https://dmcommunity.org/2018/05/01/oracle-pcs-with-dmn/"

Oracle's Process Cloud Service added a preview DMN engine with a graphical modeler and DMN XML import/export, allowing sections of a process model to be replaced by a linked decision model.
