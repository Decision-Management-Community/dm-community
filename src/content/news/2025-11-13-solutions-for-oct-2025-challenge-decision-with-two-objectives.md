<p class="wp-block-paragraph"><a href="http://dmcommunity.org/" target="_blank" rel="noreferrer noopener">DMCommunity.org</a> has already received five solutions for its <a href="https://dmcommunity.org/challenge/challenge-oct-2025/" target="_blank" rel="noreferrer noopener">Oct-2025 Challenge</a>, which asks to help a web designer to select certain website features while satisfying budget and value constraints. What makes this simple problem interesting is that it involves two conflicting objectives: total value and total cost. Potential solutions are supposed to devise a rational way to trade them against each other.<br><br>The provided solutions were created using the following tools: Seeker, Pymoo, OPL CPLEX, Copilot, and OpenRules. I decided to add one more solution based on <a href="http://rulesolver.com/" target="_blank" rel="noreferrer noopener">http://RuleSolver.com</a>. This post <a href="https://lnkd.in/eYdJAHEE" target="_blank" rel="noreferrer noopener">https://lnkd.in/eYdJAHEE</a> briefly analyzes all six solutions.</p>
