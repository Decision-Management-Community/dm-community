<p>Read this <a href="http://www.prnewswire.com/news-releases/ibm-launches-decision-composer-on-bluemix-to-help-developers-build-more-intelligent-apps-with-less-code-300431530.html" target="_blank">announcement</a> of March 29, 2017: &#8220;<em>IBM (NYSE: <a class="linkOnClick" href="http://www.ibm.com/investor" target="_blank" rel="nofollow">IBM</a>) today announced a new, experimental capability on <a class="linkOnClick" href="https://www.ibm.com/cloud-computing/bluemix/" target="_blank" rel="nofollow">Bluemix</a>, IBM&#8217;s Cloud platform, which gives developers of varying skill sets the ability to create apps that can instantly personalize a user&#8217;s experience – without the need to write complicated code.  </em><em>The new service, IBM Decision Composer, helps developers to graphically model the data and logic which drives and shapes decisions within an app.&#8221; </em><br />
IBM says &#8220;<em>Decision Composer is inspired by the <a class="linkOnClick" href="http://www.omg.org/spec/DMN/" target="_blank" rel="nofollow">Decision Model and Notation</a> standard (DMN), which is specifically devoted to describing and modeling repeatable decisions.</em>&#8221; Watch this <a href="https://youtu.be/ci3NpI37J0Q" target="_blank">video</a> that explains how it&#8217;s actually done with an Eclipse Plugin.</p>
