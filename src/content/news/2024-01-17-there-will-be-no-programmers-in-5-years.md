<p class="wp-block-paragraph">Prof. Warren Powell: &#8220;<em>Sorry, this is simply laughable. I would file this alongside Geoffrey Hinton&#8217;s prediction (circa 2016) that we will not need radiologists in 5 years (didn&#8217;t happen). Don&#8217;t these people ever learn? LLMs today certainly are useful to programmers, but only for filling in boilerplate code which can be learned from existing code. Software requires the creative guidance of a programmer to specify what task is being solved. Even with five more years of development, LLMs are never going to be able to guess what a piece of software needs to do, and my guess is that programming languages and tools will continue to evolve. My guess is that LLMs will make programmers more productive. You would think this might translate into fewer programmers, but I wouldn&#8217;t bet on this &#8211; I think we will use the same number of programmers to do more</em>.&#8221; <a href="https://www.linkedin.com/posts/warrenbpowell_there-will-be-no-programmers-in-5-years-activity-7151731893221146625-usPE?utm_source=share&amp;utm_medium=member_desktop" target="_blank" rel="noreferrer noopener">Link</a></p>
