Peter Warde published the ODM Rules Cookbook, a Git repository of source code, frameworks, blueprints,
APIs, and worked examples for building on IBM Operational Decision Manager. It's the kind of practical,
grab-and-use resource that rarely gets written up formally but saves real implementation time.
