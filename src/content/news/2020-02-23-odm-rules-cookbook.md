With the ODM Cookbook you will design and build richer, better, more maintainable and higher quality ODM rule applications. <a href="https://bitbucket.org/k-consultancy/odm-rules-cookbook/wiki/Home" target="_blank" rel="noopener">Link</a> <!--more--></p>
<p>&#8220;Unlike the ODM product samples which compile and execute with the legacy <a href="https://ant.apache.org/" rel="nofollow"><strong>Ant build tool</strong></a>, everything in the ODM Rules Cookbook is built with <a href="https://maven.apache.org/" rel="nofollow"><strong>Apache Maven</strong></a> from an <a href="https://bitbucket.org/product/" rel="nofollow"><strong>Atlassian GIT</strong></a> source repository. Examples and API&#8217;s come with <a href="https://junit.org/junit5/" rel="nofollow"><strong>JUnit 5</strong></a> tests and test harnesses, so the code is closer to production code and easier to integrate into your environment. The Cookbook also uses <a href="https://www.slf4j.org/" rel="nofollow"><strong>SLF4J logging</strong></a> to help you trace and debug your applications. It supports both SOAP and REST services using <a href="https://cxf.apache.org/" rel="nofollow"><strong>Apache CXF</strong></a>. Unlike the ODM product samples, common functionalities are shared rather than duplicated, and built using a single unified Maven build. Any development you do will be built on top of the Cookbook technology stack of Java 8, Maven and JUnit, and will be test-driven.&#8221;</p>
