<p>Machine learning is about <strong>predicting</strong>, while optimization is about <strong>solving</strong> (searching for the values of variables that lead to the best outcomes). The latest Nathan Brixius&#8217;s <a href="https://nathanbrixius.wordpress.com/2018/08/19/chaining-machine-learning-and-optimization-models/" target="_blank" rel="noopener">post</a> discusses different ways of combining optimization and machine learning:<br />
1. Optimization as a means for doing machine learning<br />
2. Machine learning as a means for doing optimization<br />
3. Using the results of machine learning as input data for an optimization model.  <a href="https://nathanbrixius.wordpress.com/2018/08/19/chaining-machine-learning-and-optimization-models/" target="_blank" rel="noopener">Link</a></p>
