<p class="wp-block-paragraph">Our <a href="https://dmcommunity.org/challenge/challenge-aug-2021/">Aug-2021 Challenge</a> follows the popular <a rel="noreferrer noopener" href="https://www.kaggle.com/c/titanic/overview" target="_blank">Kaggle</a> <a rel="noreferrer noopener" href="https://www.kaggle.com/c/titanic/overview" target="_blank">Titanic competition</a> that uses Machine Learning to predicts which passengers survived the Titanic shipwreck. In our challenge we want you to use the Kuggle training and test data to create and test a special decision model called “Titanic Booking Service”. First, you should create a decision model with rules that produce one of the following advices for each passenger: 1) Bon Voyage; 2) Go at your own risk; 3) Don’t do it! </p>



<!--more-->



<p class="wp-block-paragraph">These rules can be created using any ML tool or manually following data analysis of the data and personal interpretation of the&nbsp;<a rel="noreferrer noopener" href="https://en.wikipedia.org/wiki/Titanic" target="_blank">Titanic tragedy</a>&nbsp;(“hints from the future”). Then the decision model should apply these rules against provided test-passengers giving them a booking “advice”, comparing them with what actually happened to each passenger, and producing a summary with total numbers of Good and Bad advices. We plan to announce winners (people who produce the largest numbers of Good advices) at&nbsp;<a rel="noreferrer noopener" href="https://decisioncamp2021.wordpress.com/" target="_blank">DecisionCAMP</a>&nbsp;in September. <a href="https://dmcommunity.org/challenge/challenge-aug-2021/">Link</a></p>
