<p>Serverless architectures refer to applications that significantly depend on third-party services (knows as Backend as a Service or &#8220;BaaS&#8221;) or on custom code that&#8217;s run in ephemeral containers (Function as a Service or &#8220;FaaS&#8221;), the best known vendor host of which currently is AWS Lambda. By using these ideas, and by moving much behavior to the front end, such architectures remove the need for the traditional &#8216;always on&#8217; server system sitting behind an application. Read <a href="http://martinfowler.com/articles/serverless.html" target="_blank">more</a></p>
