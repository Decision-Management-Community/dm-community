<p>Andriy Burkov, ML at Gartner and author of <a href="https://www.amazon.com/Hundred-Page-Machine-Learning-Book-ebook/dp/B07MGCNKXB/ref=sr_1_1?gclid=CjwKCAjwlPTmBRBoEiwAHqpvhfPKq5LReuewpkfD_-JpUvufMGH12RpQfuEqxyjGVjiQcunaSnHA_RoChekQAvD_BwE&amp;hvadid=322014028317&amp;hvdev=c&amp;hvlocphy=9030955&amp;hvnetw=g&amp;hvpos=1t2&amp;hvqmt=b&amp;hvrand=1741282647934839950&amp;hvtargid=kwd-614407334867&amp;hydadcr=22594_10356234&amp;keywords=the+hundred+page+machine+learning&amp;qid=1558025574&amp;s=gateway&amp;sr=8-1" target="_blank" rel="noopener">The Hundred-Page Machine Learning Book</a>, shares <a href="https://www.linkedin.com/feed/update/urn:li:activity:6534118092346322944/" target="_blank" rel="noopener">what a good modern data analyst has to master</a>: <!--more--></p>
<ul>
<li>Data structures (local and distributed)</li>
<li>Data indexing</li>
<li>Data privacy and anonymization</li>
<li>Data lifecycle management</li>
<li>Data transformation (deduplication, handling outliers, and missing values, dimensionality reduction)</li>
<li>Data analysis (experiment design, classification, regression, unsupervised methods)</li>
<li>Machine learning methods (feature engineering, regularization, hyperparameter tuning, ensemble methods, and neural networks)</li>
<li>Computer and database programming, numerical optimization</li>
<li>Distributed data processing Real-time and high-frequency data processing</li>
</ul>
