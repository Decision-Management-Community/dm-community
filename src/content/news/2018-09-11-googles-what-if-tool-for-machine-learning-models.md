<p class="TweetTextSize TweetTextSize--jumbo js-tweet-text tweet-text" lang="en">Building effective machine learning (ML) systems means asking a lot of questions. It&#8217;s not enough to train a model and walk away. Instead, good practitioners act as detectives, probing to understand their model better: <i>How would changes to a datapoint affect my model’s prediction? Does it perform differently for various groups–for example, historically marginalized people? How diverse is the dataset I am testing my model on?</i><br />
To help to address these questions Google launched the <a href="https://ai.googleblog.com/2018/09/the-what-if-tool-code-free-probing-of.html" target="_blank" rel="noopener">What-If Tool</a>, a new feature of the open-source TensorBoard web application, which let users analyze and better understand an ML model without writing code.</p>
