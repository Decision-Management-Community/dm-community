<p class="wp-block-paragraph">Andrew Ng: &#8220;Traditional software is powered by code, whereas AI systems are built using both code (models + algorithms) and data. When a system isn’t performing well, many teams instinctually try to improve the code. But for many practical applications, it’s more effective instead to focus on improving the data&#8230; It is commonly assumed that 80 percent of machine learning is data cleaning. If 80 percent of our work is data preparation, then why are we not ensuring data quality is of the utmost importance for a machine learning team?&#8221; <a rel="noreferrer noopener" href="https://analyticsindiamag.com/big-data-to-good-data-andrew-ng-urges-ml-community-to-be-more-data-centric-and-less-model-centric/" target="_blank">Link</a></p>
