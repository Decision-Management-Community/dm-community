<p class="wp-block-paragraph"><a href="https://www.linkedin.com/in/martinmilani/" target="_blank" rel="noopener">Martin Milani</a> wrote today: &#8220;<em>MCP gives agents tools to read your files, read/send your emails, and query IT systems. It&#8217;s what makes agents actually useful. It&#8217;s also a wide-open door. There’s no inherent concept of security in MCP. No framework. No trust hierarchy. No way for the agent to distinguish between &#8220;my user told me this&#8221; and &#8220;a webpage told me this.&#8221; They land in the same context window with the same authority.</em></p>



<p class="wp-block-paragraph"><em>Malicious font files injected into webpages could manipulate agents into leaking sensitive data through MCP-enabled tools. The trap reads the page. MCP executes the action. Data leaves the building. Nobody noticed.</em></p>



<p class="wp-block-paragraph"><em>Every enterprise MCP implementation is custom. Every implementation is different. There is no standard security framework. Which means there is no standard defense. Attackers need to find one gap in one implementation. Defenders need to secure all of them. The era of AI viruses has begun.</em>&#8221;  <a href="https://www.linkedin.com/posts/martinmilani_ai-agent-traps-share-7465056241556402176-tijz/?utm_source=share&amp;utm_medium=member_desktop&amp;rcm=ACoAAAAFIMoBtgF6zELsOiwFm0hGYH1dIteE6pQ" target="_blank" rel="noopener">Link</a></p>
