The question: is Java not free anymore?<!--more--> <a href="http://www.javamagazine.mozaicreader.com/NovemberDecember2018#&amp;pageSet=52&amp;page=0&amp;contentItem=0" target="_blank" rel="noopener noreferrer">Dec-2018 issue of Java Magazines</a> explains the changes in Oracle Java Licensing policy. In particular, it says: &#8220;<em>If you are accustomed to getting Java SE binaries for free, you can simply continue doing so with OpenJDK builds from Oracle avaiable at <a href="http://jdk.java.net" target="_blank" rel="noopener noreferrer">jdk.java.net</a></em>&#8220;. However, this link tells you: &#8220;<em>This page provides production-ready open-source builds of the <a href="http://openjdk.java.net/projects/jdk/11/" target="_blank" rel="noopener noreferrer">Java Development Kit, version 11.0.2</a>, an implementation of the <a href="http://openjdk.java.net/projects/jdk/11/spec/" target="_blank" rel="noopener noreferrer">Java SE 11.0.2 Platform</a> under the <a href="http://openjdk.java.net/legal/gplv2+ce.html" target="_blank" rel="noopener noreferrer">GNU General Public License, version 2, with the Classpath Exception</a>.</em>&#8221; But GNU GPL license requires your application to also be open-sourced or you need to use the Commercial builds of JDK 11.0.2 from Oracle under a <a href="https://www.oracle.com/technetwork/java/javase/terms/license/javase-license.html" target="_blank" rel="noopener noreferrer">non-open-source license</a>.</p>
<p>Oracle also says that <a href="https://www.oracle.com/technetwork/java/javase/overview/faqs-jsp-136696.html" target="_blank" rel="noopener noreferrer">Java SE 8</a> &#8220;<em>remains free of charge for general purpose desktop and server use and is available under the Oracle Binary Code License (<a href="https://www.oracle.com/technetwork/java/javase/terms/license/index.html" target="_blank" rel="noopener noreferrer">BCL</a>) at <a href="https://www.oracle.com/javadownload" target="_blank" rel="noopener noreferrer">https://www.oracle.com/javadownload</a></em>.&#8221; However,  <em>Oracle <a href="https://www.oracle.com/technetwork/java/javase/overview/index.html" target="_blank" rel="noopener noreferrer">warns</a> that it &#8220;will not post further updates of Java SE 8 to its public download sites for commercial use after January 2019. Customers who need continued access to critical bug fixes and security fixes as well as general maintenance for Java SE 8 or previous versions can get long term support through Oracle Java SE Subscription or Oracle Java SE Desktop Subscription</em>.&#8221;<b></b></p>
