<p>&#8220;Machine learning is often <a href="https://en.wikipedia.org/wiki/Machine_learning" target="_blank">touted</a> as <em>a field of study that gives computers the ability to learn without being explicitly programmed</em>. Despite this common claim, anyone who has worked in the field knows that designing effective machine learning systems is a tedious endeavor, and typically requires considerable experience with machine learning algorithms, expert knowledge of the problem domain, and brute force search to accomplish. Thus, contrary to what machine learning enthusiasts would have us believe, <em>machine learning still requires a considerable amount of explicit programming</em>.&#8221; Read more at this <a href="http://www.randalolson.com/2016/05/08/tpot-a-python-tool-for-automating-data-science/" target="_blank">Randal Olson&#8217;s post</a>.</p>
